# Pathwise name and branding

Pathwise's code is open source (GPL-3.0) and its bundled guides are CC BY-SA 4.0.
Those licenses cover the code and the data. They do not cover the project's name and
branding, which are kept separately so players can always tell which add-ons come from
the Pathwise project.

## What is covered

- The name "Pathwise".
- The tagline "Every quest. Every craft. Every level."
- Pathwise logos and icons, if any are published.
- The Pathwise family: add-ons published by the Pathwise project (leight_nn and florp)
  whose names start with or contain "Pathwise", for example "Pathwise" itself,
  "Pathwise Gear", "Pathwise Bags", and official data or companion add-ons.

These are used as trademarks of the Pathwise project.

## What you can do without asking

- Say that your add-on, guide or video works with Pathwise, is a route pack for
  Pathwise, or is based on Pathwise, as long as it is true.
- Redistribute unmodified official Pathwise releases under their original name.
- Use the name in reviews, tutorials, news and discussion.

## What needs permission

- Publishing a modified version or fork under the name Pathwise, or under a name that
  could be confused with it. Forks must use a different name and remove Pathwise
  logos.
- Naming a community add-on so it looks official. Use "<Your name> for Pathwise" or
  "<Your name> route pack", not a name that starts with "Pathwise".
- Using Pathwise branding in a way that suggests endorsement by the Pathwise project.
