## What is and is not covered

- Covered: the selection, the notes, the skill levels kept as labelled
  fallbacks and the verification flags written for this project.
- Not covered, because they are facts about the game rather than creative
  work: recipe, item and NPC IDs and names, reagent quantities and zone
  names. These belong to Blizzard Entertainment and are used here only to
  identify in-game content. Each file says where they were checked
  (Wowhead's World of Warcraft: Forever database).

license, which they declare in their `license` field. The code license
(GPL-3.0) does not apply to data-only packs; see the additional permission
in NOTICE.md.
